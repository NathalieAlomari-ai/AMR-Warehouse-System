How Navixa Works

Three steps from order to delivery — fully autonomous

📋

Place Order

Operator enters a shelf ID (e.g. SHELF_A07) in the dashboard. The command is instantly sent to the robot via MQTT over the local network.

🧭

Robot Navigates

Navixa builds a real-time map using LiDAR SLAM and navigates to the target shelf, scanning QR codes and detecting the correct medicine box with AI vision.

📦

Box Delivered

The suction-based lifting system picks the box and delivers it to the drop zone. The operator is notified in real time — order marked complete.
