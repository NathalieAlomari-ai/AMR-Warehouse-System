How Navixa Works

Three steps from order to delivery — fully autonomous

📋

Place Order

Operator enters a shelf ID in the dashboard. The command is instantly sent to the robot via MQTT over the local network.

🧭

Robot Navigates

Navixa builds a real-time map using LiDAR SLAM, navigates to the shelf, and identifies the medicine box with AI vision.

📦

Box Delivered

The suction-based lifting system picks the box and delivers it to the drop zone. Order marked complete in real time.
